# EKS Service Validations

This directory contains resources and references for validating Amazon EKS (Elastic Kubernetes Service) deployments as part of the AWS Competency Center's service validation work.

## Contents

- **Validation code** — Scripts, configurations, manifests, and templates used to validate EKS clusters and workloads
- **Architecture references** — Diagrams and documentation describing validated EKS architectures

## Folder Structure

The structure within this directory is flexible, but typically includes:

```
snippets/         # EKS code samples, manifests, policies, and validation resources
architectures/    # EKS architecture diagrams and supporting documentation
```

Other subfolders may be added as needed for specific use cases or team requirements.

## Contributing

1. Add EKS validation code, manifests, and configuration files under `snippets/`.
2. Add EKS architecture diagrams and documentation under `architectures/`.
3. Follow repository-wide contribution guidelines and maintain the top-level folder structure.
